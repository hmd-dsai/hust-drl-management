# HUST DRL Tracker

Quản lý điểm rèn luyện HUST: nhập hoạt động → tự tính điểm theo rubric có trần nhiều tầng → gợi ý cách gán tiêu chí tối ưu.

Đang trong giai đoạn phát triển. Xem `docs/SPEC.md` (đặc tả) và `docs/PROMPTS.md` (kế hoạch triển khai).

- `schema/` — JSON Schema cho rubric và dữ liệu người dùng
- `data/rubrics/` — rubric cũ (2025.1–2025.2) và rubric mới (từ 2026.1), trích từ Google Sheet cũ
- `data/samples/` — dữ liệu mẫu học kỳ 2026.1 và kết quả tính điểm kỳ vọng
